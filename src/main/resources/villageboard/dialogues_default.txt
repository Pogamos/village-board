# Répliques des villageois (Village Board)
#
# Une réplique par ligne, rangée sous une section entre crochets. Les lignes qui commencent par # sont ignorées.
# Le fichier est relu automatiquement dès qu'il est enregistré : pas besoin de redémarrer le serveur.
#
# Quand un joueur parle à un villageois, une réplique est tirée au hasard parmi toutes les sections qui le concernent :
#   [tous]          tous les adultes
#   [enfant]        les enfants (ils ne disent que ces répliques ; à défaut, celles de [tous])
#   un métier       [armurier] [boucher] [cartographe] [clerc] [fermier] [pecheur] [archer] [maroquinier]
#                   [bibliothecaire] [macon] [berger] [outilleur] [forgeron] [niais] [sans_emploi]
#                   (les identifiants vanilla marchent aussi : [farmer], [minecraft:librarian]…)
#   [sans_abri]     n'a pas de lit
#   [marie]         est marié          [veuf]    a perdu son conjoint     [celibataire]  n'a jamais été marié
#   [parent]        a au moins un enfant
#   [nuit]          il fait nuit       [pluie]   il pleut
#
# Variables : {joueur} {nom} {metier} {village} {conjoint}
# Une réplique qui utilise une variable sans valeur est écartée : {nom} pour un villageois sans nom,
# {conjoint} pour un célibataire, {village} hors de tout village.
